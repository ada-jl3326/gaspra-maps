# Gaspra: interactive impact maps

Interactive maps for the poster of group Gaspra (Deep Impact project,
Applying Computational & Data Science, Imperial College London, 2026).

Live site: https://ada-jl3326.github.io/gaspra-maps/

- `scenario.html`: one impact, with the ground track and elliptical damage zones
- `compare.html`: circular and elliptical damage zones for the same impact
- `risk.html`: probability of being inside the 27 kPa zone over 50,000 sampled impacts

This repository holds only the generated maps (made with folium); the code
is in the group's private course repository.
Map data © OpenStreetMap contributors. Population: 2011 UK census grid.
